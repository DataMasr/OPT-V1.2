Emulator High CPU Priority

PRIORITY

Starts GameLoop's engine processes (AndroidEmulator + aow_exe) at High CPU priority so the game is scheduled first. Uses Windows' own per-app priority setting - applies the next time GameLoop starts.

Force Dedicated GPU + Windowed Game Optimizations

GPU

Pins GameLoop to your high-performance GPU (huge on Intel + NVIDIA laptops) and enables Windows' flip-model and variable refresh optimizations for windowed games.

GameLoop Engine Render Boost

EMULATOR

Turns on GameLoop's own shader caches and render optimization and turns VSync off for lower input lag. Applies the next time GameLoop starts.

Stop GameLoop Auto-Start

EMULATOR

Uses GameLoop's own setting so it no longer launches with Windows - faster boot and free RAM until you actually play.

MMCSS Games Priority Profile

SYSTEM

Configures Windows' multimedia scheduler to give game threads high CPU and I/O priority.

System Responsiveness + Network Throttle Off

SYSTEM

Reserves 10% of CPU for background tasks instead of 20% and removes Windows' multimedia network throttling for lower input-to-action latency.

Windows Game Mode

SYSTEM

Windows Game Mode prioritizes the game and holds back update installs while you play - on by default in Windows 10/11. The same switch as in Windows Settings.

Disable Game DVR / Xbox Game Bar Recording

GAMEBAR

Turns off background game recording - frees CPU/GPU and removes a common stutter source.

Disable Mouse Acceleration

INPUT

Turns off "Enhance pointer precision" so mouse aim in GameLoop is consistent 1:1. Applies immediately.

Disable Update Sharing (Delivery Optimization P2P)

NETWORK

Stops Windows Update from uploading updates to other PCs through your connection - steadier ping. The same switch as in Windows Settings.
